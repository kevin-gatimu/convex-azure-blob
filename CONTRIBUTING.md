# Contributing

Thanks for helping. Bug reports and pull requests are welcome at
<https://github.com/kevin-gatimu/convex-azure-blob>.

## Layout

| Path                        | What it is                                                                                        |
| --------------------------- | ------------------------------------------------------------------------------------------------- |
| `src/component/`            | The Convex component: the `files` table (`schema.ts`) and its functions (`lib.ts`).               |
| `src/client/`               | The `AzureBlob` class apps use, SAS signing (`sas.ts`) and the file signature check (`sniff.ts`). |
| `src/react/`                | `useUploadFile` and `uploadToAzure`.                                                              |
| `src/test.ts`               | The `convex-azure-blob/test` helper for convex-test.                                              |
| `example/`                  | An app that installs the component: `example/convex` backend, `example/src` UI.                   |
| `scripts/azurite-setup.mjs` | Creates the container and CORS rule on a local Azurite.                                           |

`src/component/_generated/` is generated by Convex. Commit it after changing the
component's functions or schema.

## Running locally

```sh
npm install
docker compose up -d azurite
npm run azurite:setup
npm run dev            # builds the package on change and runs the example backend
npm run dev:frontend   # the example UI on http://localhost:5173
```

`npm run dev` sets up a Convex deployment for the example on its first run. Then
set the `AZURE_BLOB_*` variables that `azurite:setup` prints with
`npx convex env set`.

## Checks

```sh
npm run build:codegen  # component codegen, then build to dist/
npm run typecheck
npm run lint
npm test
npm run test:package  # tarball imports and upload flow with minimum peers
```

`npm run check` runs all release checks, including the isolated consumer test.
The consumer test requires registry access; component codegen additionally
requires your configured Convex development deployment.

The tests run with Azure stubbed. To also run the integration tests against
Azurite, which checks real SAS signatures:

```sh
docker compose up -d azurite && npm run azurite:setup
AZURITE_BLOB_ENDPOINT=http://127.0.0.1:10000/devstoreaccount1 npm test
```

Formatting is Prettier (`npm run format`).
